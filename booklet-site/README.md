# PHYTO MOTION — Interactive Booklets

موقع مستقل للكتيّب التفاعلي، منفصل عن واجهة PHYTO MOTION الأساسية. لا يعتمد على ملفات خارج هذا المجلد؛ الصور محفوظة محليًا في `assets/`، والصفحة تعمل دون مكتبات أو خدمات خلفية.

## نشره كموقع مستقل على Vercel

أنشئ **مشروع Vercel جديدًا** لهذا الموقع، ولا تغيّر إعدادات مشروع PHYTO MOTION الحالي:

1. استورد مستودع Git نفسه كمشروع Vercel جديد.
2. اجعل **Root Directory** هو `booklet-site`.
3. اختر **Other** كـ Framework Preset، من دون أمر بناء أو اعتماديات.
4. انشر المشروع الجديد، ثم اربط به النطاق الذي تريده.

بهذا يكون للموقع رابط ونشر مستقلان، ولا تظهر بوابة الكتيّب كرابط أو صفحة داخل الموقع الأساسي. عند معاينة الفرع الحالي، يمكن فتحه عبر `/booklet-site/`.

## تشغيل محلي

افتح `index.html` مباشرة، أو من جذر المستودع شغّل:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000/booklet-site/`.
